AI Driver Risk Monitor

An AI-powered smart driving safety platform that analyzes driver behavior, predicts driving risk, and provides real-time safety insights through an interactive web application.

Overview

AI Driver Risk Monitor is designed to improve road safety by combining multimodal inputs such as sensor values, driver condition text, and driver image analysis. The system predicts driver risk levels and provides actionable recommendations through a modern dashboard interface.

Key Features

* Live Risk Meter – Real-time driver risk percentage visualization
* Driver Status Prediction – Classifies driving state into Safe / Medium Risk / High Risk
* Smart Route Map – Interactive map with destination routing
* Driver Image Analysis – Basic alertness / visibility estimation from uploaded images
* Voice Alerts – Spoken warning when high-risk driving is detected
* Trip History Storage – Permanent session history saved locally
* Downloadable Reports – Export driving reports in CSV format
* AI Suggestions Engine – Personalized safety recommendations
* Responsive Futuristic UI – Mobile-friendly cyber dashboard design
